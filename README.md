Karma Launcher is a free, modern open-source home app for Android. Taking Launcher3—Android’s default home app—as a starting point, it delivers Pixel Launcher features and introduces rich customization options with a modern minimalist aesthetic.

This branch houses the codebase of Karma Launcher (based on Android 16 Launcher3).

## Features

- Material 3 Expressive theming that follows your wallpaper and system colors.
- Geometric minimalist "K" vector adaptive icon with Android 13+ Themed Icons support.
- Modern default 5×5 workspace and app drawer layout.
- At a Glance widget support, with integration for [Smartspacer](https://github.com/KieronQuinn/Smartspacer).
- QuickSwitch support for Android Recents integration on Android 15-16 (root required).
- Global search for apps, contacts, and web results from the home screen.
- Customization options for icon packs, fonts, and layout settings.
